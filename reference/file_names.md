# stats19 file names for easy access

URL decoded file names. Currently there are 52 file names released by
the DfT (Department for Transport) and the details include how these
were obtained and would be kept up to date.

## Format

A named list

## Note

These were generated using the script in the `data-raw` directory
(`misc.Rmd` file).
